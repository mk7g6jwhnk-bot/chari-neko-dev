# オート統合版0.3

処理:
1. autorace.jp開催情報取得
2. 各場LIVEページ
3. 出走表・オッズ内部リンク発見
4. 車番・選手名・ハンデ・試走・走路状態取得
5. 良・湿・斑・不明を分離
6. エンジン入力変換
7. 着順別評価
8. 展開枝
9. 全終端
10. 監査
11. 本線・押さえ・買える万車・厚め
12. 合成オッズ
13. 資金配分
14. 結果表示

安全策:
- 試走未発表を欠損扱い
- 走路不明時は良走路へ断定しない
- オッズ未取得終端は購入不採用として保持
- 終端削除禁止
- 事故・接触は予想枝として保持するが、結果学習時は客観情報がなければ判定保留
