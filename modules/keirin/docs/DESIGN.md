# 競輪統合版0.4

処理:
1. KEIRIN.JP開催日程取得
2. 同一Cookie・Refererで開催ページへ移動
3. 出走表・オッズ内部リンク発見
4. 出走表解析
5. 公式並び表記解析
6. ライン信頼度判定
7. 競輪エンジン入力変換
8. 着順別評価
9. 展開枝
10. 全終端
11. 監査
12. 本線・押さえ・買える万車・厚め
13. 合成オッズ・資金配分

重要:
- 公式ラインが取れない場合はライン信頼度「低」
- ライン信頼度「低」の場合、先行押し切り・番手差し・ラインまくり・番手離れ枝は停止
- 推測ラインを確定扱いしない
- オッズ未取得終端は購入不採用として保持
